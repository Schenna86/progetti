PIRATE TREASURE - V6 DESIGNER VISUALE
=====================================

Questa versione aggiunge un editor visuale direttamente alla pagina.

Premi il pulsante 🛠 in alto a sinistra.

Puoi selezionare e modificare:
- Frame
- Rulli
- Logo
- Linee
- Puntata
- Totale giocata
- Vincita
- Pulsante SPIN

Uso:
1. attiva 🛠
2. clicca un elemento
3. trascina il rettangolo azzurro per spostarlo
4. trascina il pallino in basso a destra per ridimensionarlo
5. puoi inserire X/Y/W/H numericamente
6. Copia CSS produce i valori finali
7. Salva locale conserva il layout in localStorage
8. Reset torna ai valori originali del CSS

NOTA
----
L'altezza è indipendente solo per la griglia rulli.
Per frame/logo/pannelli/SPIN il ridimensionamento lavora sulla larghezza,
mantenendo la forma dell'immagine.
